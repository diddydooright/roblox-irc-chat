# IRC Client for Roblox
### What does it do?  
It allows you to chat, free of roblox's tyranny, on any roblox game, with anyone in the same server who is also running this client.  
This is not a mod for roblox, as it is just an overlay that runs over your game window and uses the logs to find the unique id of the server you are joining.  
This id is just the unique identifier of the server you are joining, so its not getting any personal info from your account or anything.
What makes this work is the UUID of any one server is consistent for all players joining it, so the irc channel you join will be the same.

### How do i run it?
You need python then you just run the ```run.bat``` file and join a game and it should work.  
Join a game with your friend and both of you running the client, and you will be able to swear in roblox😈(technically outside of roblox)  
To set your nickname, use the config.json file and make sure to keep the quotes where they should be.  
One issue is when you start the client while in game, you will have to rejoin for it to detect that you have joined a game.
